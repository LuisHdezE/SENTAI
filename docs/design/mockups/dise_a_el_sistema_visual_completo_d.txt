Diseña el sistema visual completo de una plataforma logística llamada SENTAI.

SENTAI es una plataforma de gestión de almacenes, inventario, pedidos, fulfillment, picking, packing, planificación de envíos y control financiero de clientes.

La solución tiene tres experiencias diferenciadas:

1. SENTAI Backoffice Web
   Para administradores, supervisores de almacén, personal de operaciones, planificación, comercial y finanzas.

2. SENTAI Customer Portal
   Para clientes que consultan catálogo, disponibilidad, crean pedidos, revisan envíos, saldos, cuentas por pagar y estado de cuenta.

3. SENTAI Operator Mobile
   Aplicación operativa para Android e iOS utilizada por personal de almacén para recepción, put-away, picking, movimientos, conteos y otras tareas físicas.
